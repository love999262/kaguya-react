## Purpose

为整站提供日间/夜间双主题与"日间/夜间/跟随系统"三态开关：定义主题模式的管理、持久化、系统偏好跟随、根节点主题应用，以及两套主题下各组件视觉令牌的行为契约。

## ADDED Requirements

### Requirement: 主题模式三态管理与持久化
系统 SHALL 支持三种主题模式：`light`（日间）、`dark`（夜间）、`system`（跟随系统）。首次访问未保存选择时 MUST 默认为 `system`。用户的选择 MUST 持久化到 localStorage，并在后续每次加载时于首屏绘制前恢复，避免主题闪烁。

#### Scenario: 首次访问默认跟随系统
- **WHEN** 用户首次打开页面且 localStorage 无主题记录
- **THEN** 主题模式为 `system`，页面按操作系统 `prefers-color-scheme` 呈现对应主题

#### Scenario: 选择被持久化并在下次加载生效
- **WHEN** 用户通过开关选择某一模式后重新打开页面
- **THEN** 页面在首屏绘制前即应用上次保存的模式，不出现先闪另一种主题再切换的现象

#### Scenario: 持久化数据损坏时安全回退
- **WHEN** localStorage 中的主题值不是 `light|dark|system` 之一
- **THEN** 系统回退为 `system` 模式且不抛出异常

### Requirement: 跟随系统实时响应
当模式为 `system` 时，系统 SHALL 以 `prefers-color-scheme: dark` 是否匹配决定呈现夜间或日间主题，并 MUST 监听系统偏好变化实时切换，无需刷新页面。模式为 `light` 或 `dark` 时 MUST 不受系统偏好变化影响。

#### Scenario: 系统偏好变化时实时切换
- **WHEN** 模式为 `system` 且操作系统从浅色切换到深色
- **THEN** 页面不刷新即切换为夜间主题

#### Scenario: 强制模式不受系统影响
- **WHEN** 模式为 `light` 且操作系统切换到深色
- **THEN** 页面保持日间主题

### Requirement: 右上角三态主题开关
系统 SHALL 在页面右上角提供常驻主题开关，包含"日间/夜间/跟随系统"三个选项，且 MUST 高亮当前生效的模式。每个选项 MUST 有图标与文字提示（tooltip），并支持键盘操作与屏幕阅读器语义（radiogroup/aria-checked 或等价语义）。

#### Scenario: 点击切换模式
- **WHEN** 用户点击"日间"选项
- **THEN** 模式变为 `light`，页面立即切换为日间主题，开关高亮"日间"

#### Scenario: 键盘可访问
- **WHEN** 用户使用 Tab 聚焦开关并以方向键/回车切换选项
- **THEN** 选项依次获得焦点且可激活，行为与点击一致

### Requirement: 双主题视觉令牌契约
所有组件的颜色（表面、文字、边框、阴影、强调色）SHALL 通过统一设计令牌（CSS 自定义属性）取值；`light` 与 `dark` 两套主题 MUST 各自提供完整令牌集。日间主题 MUST 为浅色玻璃面板 + 深色文字；夜间主题 MUST 保持现有深色玻璃 + 浅色文字的整体观感。两套主题下正文文字与面板背景的对比度 MUST 不低于 4.5:1。

#### Scenario: 组件不硬编码主题色
- **WHEN** 任一组件样式需要随主题变化的颜色
- **THEN** 该颜色通过令牌变量引用，而非写死的浅色或深色值

#### Scenario: 日间主题可读性
- **WHEN** 页面处于日间主题
- **THEN** 面板为浅色半透明玻璃风格、文字为深色，搜索框/日历/时钟/深度模式面板均呈现日间风格

#### Scenario: 夜间主题延续现有观感
- **WHEN** 页面处于夜间主题
- **THEN** 面板为深色半透明玻璃风格、文字为浅色，与改版前夜间视觉一致或更统一

### Requirement: 导航网站表格主题适配
导航网站分类表格 SHALL 随主题切换，且 MUST 与日历面板共用同一套玻璃令牌（容器 `--kg-surface`、单元格 `--kg-surface-soft`、分隔线 `--kg-border`、文字 `--kg-text`），不单独维护表格色板：夜间主题下为深色玻璃（消除纯白刺眼底），日间主题下为与日历一致的浅色玻璃；分类标题的彩色渐变 MUST 保留；相邻列与相邻行之间的分隔线 MUST 只绘制一条，且 MUST 不使用斑马纹交替底色。

#### Scenario: 夜间不再出现纯白大表格
- **WHEN** 页面处于夜间主题
- **THEN** 网站表格底色为深色半透明，文字浅色，悬停态清晰可辨

#### Scenario: 日间表格与日历同风格
- **WHEN** 页面处于日间主题
- **THEN** 网站表格呈现与日历面板一致的浅色玻璃底、深色文字与白色高光边框，分类头部渐变保留，格子底色统一无斑马纹

#### Scenario: 分隔线不重叠
- **WHEN** 任一主题下查看网站表格
- **THEN** 列与列、行与行之间均为单条 1px 分隔线（列间负外边距合并、单元格仅上边框），无双线叠加

### Requirement: 壁纸随主题处理
日间与夜间模式 SHALL 复用同一随机壁纸。日间模式 MUST 在壁纸上叠加白色系半透明提亮遮罩（`--kg-overlay` + `--kg-overlay-filter`），消除暗画布带来的黄昏感、呈现标准日间观感；夜间模式 MUST 保持壁纸原始观感（遮罩 transparent/none）。

#### Scenario: 日间模式壁纸提亮
- **WHEN** 页面切换到日间主题
- **THEN** 壁纸呈现提亮偏白的标准日间观感，浅色玻璃面板在其上清晰可读且不显黄昏感

#### Scenario: 切换壁纸不破坏主题
- **WHEN** 用户按 ` 键切换随机壁纸
- **THEN** 当前主题的遮罩处理保持不变

### Requirement: 画布时钟主题适配
canvas 绘制的时钟 SHALL 根据当前生效主题选择配色：夜间使用深色表盘浅色指针文字，日间使用浅色表盘深色指针文字；随机变化仅发生在当前主题允许的配色集合内。

#### Scenario: 时钟配色跟随主题
- **WHEN** 页面从夜间切换到日间主题
- **THEN** 时钟表盘/数字/指针配色切换为日间集合，且在浅色背景上清晰可读
